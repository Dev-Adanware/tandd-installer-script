# AMT T&D Deployment

Choose an installation method:

- **Online:** Install release `v1.23.2-lic-3` from the internet. The Linux server needs outbound internet access and the GitHub token provided by ADANWARE.
- **Offline:** Ask ADANWARE for the corrected `v1.23.2-lic-3` package and its checksum. The target server does not need internet access. It needs Docker, Docker Compose, sudo access, and Python 3.

Check the [IT prerequisites](./1-IT_Prerequisites.md). The [Deployment Guide](./2-Deployment_USER_GUIDE.md) has copy-ready commands for both methods, license activation, login, and configuration.
