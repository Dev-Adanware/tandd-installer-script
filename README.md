# AMT T&D Deployment

Choose an installation method:

- **Online:** Install release `v1.24.0` from the internet. This installer supports clean installations only. If you already have an installation, contact ADANWARE before replacing or changing it.
- **Offline:** The available offline package is `v1.23.2-lic-3`. Ask ADANWARE for the package and its checksum. The target server does not need internet access. It needs Docker, Docker Compose, sudo access, and Python 3. An offline v1.24.0 package is not yet available.

Check the [IT prerequisites](./1-IT_Prerequisites.md). The [Deployment Guide](./2-Deployment_USER_GUIDE.md) has copy-ready commands for both methods, license activation, login, and configuration.
